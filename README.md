# Hytale

Git home for Inigmas Games' Hytale work. This repository consolidates the authored source and durable project records previously stored in Google Drive.

- `hytale-taverns/` — Hytale Taverns source, authored assets, scripts, and design documents.
- `persistent-npcs/` — Immersive/Persistent NPC source, resources, tests, technical documentation, training tooling, and reports.
- `orbis-offline-training/` — Orbis training registries, candidate metadata, datasets, reports, and quarantine records.

See `MIGRATION_MANIFEST.md` for the migration boundary and exclusions.
