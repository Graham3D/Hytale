## New command and ownership

`/rpg-heal-probe channel none` arms a 30-second observer in the existing world, restricted by the existing administrative permission. It does not cast a skill. The owner then casts Healing Beam normally, with its existing equipment, target, Mana and lifecycle requirements.

The observer records real presentation skill-instance IDs separately from its probe generation. It reads each carrier's runtime UUID, NetworkId, model/texture/particle fields, bounds and position; each recipient/staff effect's controller presence, exact asset index and `hasEffect` state; the actual sorted native system indices; native viewer tracking; non-consuming copies of queued updates; and the outbound packet watcher boundary. First and second frame state snapshots distinguish initial construction from a subsequent frame without serializing models every tick.

Native effect Add and Remove transitions are recorded separately at queue and outbound boundaries, filtered to the exact expected production effect IDs. An initial component snapshot must not hide a later effect removal through deduplication. Native queue observation is not packet acknowledgment, and the outgoing watcher is not client rendering proof. No `CLIENT_RENDERED` or transport acknowledgment is fabricated.

The observer allocates no presentation entity, adds/removes no effect, modifies no NPC/player state, and never calls a queue-consuming method. It runs reads synchronously inside the presenter's existing safe world phase. Exceptions are contained so diagnostic failure cannot redirect gameplay or presenter cleanup. Stopping the observer unregisters its window; it **does not stop or clean up a real channel**. Release the skill normally to exercise real production cleanup.

Bounds: four worlds maximum, one run per world, 30 seconds for CHANNEL (the eight old controls retain ten seconds), eight observed channels per run, 64 watched network entities, 128 distinct diagnostic transition receipts plus summary, and the retained two-second removal-observation tail. Suppressed diagnostic transition attempts are counted explicitly in the summary. These are observation limits, not limits imposed on gameplay. A capped capture is incomplete and must not be treated as a passing lifecycle result.
