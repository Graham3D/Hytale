# R241 natural spawn throughput and Elite birth

The connected R240 trace `monster-spawn-1791510259237.jsonl` recorded 2,114 native jobs in two minutes; 1,722 selected Frostgill, Trilobite, or Snapjaw. Their cave spawn asset offered all three on `Rock` without the `Water` fluid tag used by Hytale's other aquatic spawn tables. The R241 asset override retains the same five cave environments, three role IDs, and weights, but applies native `SpawnFluidTag: Water` eligibility to each fish. It removes the erroneous dry-rock placement path while allowing cave pools and leaving other fish tables, native budgets, and the operator's density configuration intact. Native world spawning still owns role selection and finite job retries; the connected R241 trace is needed to measure the actual job-throughput improvement.

Hytale's `FlockPlugin.trySpawnFlock` may create members with concrete roles from the leader's authored `FlockSpawnTypes`. R240 capture incorrectly required every member's role name to equal the lead job role, even though Hytale assigns the same job role index, environment, and spawn configuration to those members. R241 retains those exact provenance checks, captures the full roster, and classifies each concrete member with its own certified binding. The first actor must still match the job's lead role. Unbound or invalid members still trigger one pre-root native rollback.

Native singleton bears have no `FlockMembership` before expansion. The installed `FlockPlugin.trySpawnFlock` explicitly creates a native flock when membership is absent; R241 permits that native route, including a null flock asset for the installed bear spawn tables. A flock created solely for a declined extension is removed with its captured members during rollback. Accepted groups keep the native flock.

The terrestrial 65/35 classification now treats Squirrel and other installed passive critter-template roles as wildlife. Fox is wildlife for this controller because its authored predator variant flees when unthreatened. This changes population weight classification only; native combat, Elite eligibility, and aquatic/avian exemptions remain separate.

`/rpg spawntrace` keeps bounded details and rare-event priority rows. The output now includes twelve 10-second bucket records with job starts/completions, native placement rejection counts, NPC additions by population category, removals by reason, native population and job budget samples, Elite publications/fallbacks, and current active-pack leases. Buckets continue accumulating after detail rows fill.
