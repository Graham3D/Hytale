# Passive icons go here

Save transparent PNGs using the exact filename in [the complete list](../ICON-FILENAMES.csv).
Example: `PassivePotency.png` or `PassiveSharedaegis.png`.
Recommended: 128 x 128 pixels, transparent background, no baked-in slot frame.

Close Hytale, double-click **Update RPG Icons.cmd** in the repository root,
then start Hytale and rejoin RPG.
See [the instructions](../ADDING-ICONS.md).
