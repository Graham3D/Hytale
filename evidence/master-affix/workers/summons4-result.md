## Implemented in this ownership

- WA-115: ordinary NPC native Physical/Projectile armor/effect protection is read through the installed `DamageSystems.ArmorDamageReduction` map at spawn and frozen on the lease. `DamageGuard` applies only the D01 rating bonus delta above the native reduction already applied by the engine. No new summon chassis was invented.
- WA-117: `SummonNativeActions` selects an exact per-spawn Skeleton Archer role for a frozen WA-117 roll. `Generate-SummonCommandAssets.ps1` generated 209 roll variants (3.2–24.0%, 0.1-point grid), each with a role, root action, interaction and Shoot animation. Each root contains one action; each action contains one `LaunchProjectile` for `Skeleton_Archer_Arrow`. Native preparation, release and animation speed use the same accepted V. The RPG arrow admission clock uses the actual 1.2 s native baseline divided by `1+V/100`, so it admits one native arrow per completed attack. The unmodified role remains the zero-roll path. Melee summons continue to use their existing RPG attack scheduler; they have no native projectile release.
- Sentinel WA-117 presentation: `NativeSentinelActionAssets` publishes an exact frozen-rate `ItemPlayerAnimations` variant through Hytale's supported asset store at spawn/restore. The actual Sentinel hit callback plays this variant; the rate includes the bound source's WA-008 and the owner's committed WA-117 once each. This scales the native swing presentation with the RPG claim period without changing the permanent actor's source conversion or launching extra projectiles. The stock NPC melee root remains a native behavior/telegraph and its damage remains rejected by `DamageGuard`.
- D12 direct channels: the Sentinel forge gate now admits WA-007 and WA-017–040. Their bound-source local flat, elemental Increased, penetration and conversion values are already assembled in the shared `GearCombatEffects.attack` hit and submitted through the native channel adapter with the Sentinel actor/root/contact/item witness. Weapon-local flat/conversion rolls are rejected on armor sources. A positive bound Wind source/control actor witness test was added. This grows the explicit `ADAPTED` source set from 19 to 44; 56 OWNER_ONLY dispositions remain intentional, and 60 compatible source IDs remain gated pending their distinct native consumers.
- D08: `NativeSentinelItemAuras` constructs fixed rank-one contexts from the exact bound item with neutral NPC attributes, and calls the item worker's `HytaleSupportSystem` Sentinel activation/tick/detach APIs. It implements bounded native ally membership, includes the owner when in range and valid, and exposes strongest-valid Mana regeneration, cooldown recovery and Thorns queries composed with player Auras. `HytaleSummonSystem.configureSentinelItemAuras` is a ready injection point. The summon tick starts/ticks the Aura only after the durable Sentinel ledger reports ACTIVE, and cleanup calls run on death, replacement, world transfer, voluntary dismissal, restore failure and native removal. The Aura IDs remain forge-gated until main wires these queries into the support/status observers and runs native tests.
- WA-113/114/116/118/119 retain the production consumers reported by `summons3-result.md` and `summons-result.md`; no gate was enabled here. Their committed owner source remains the schema-3 ledger snapshot, independent of later equipment swaps.
