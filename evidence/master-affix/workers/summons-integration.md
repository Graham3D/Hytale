# Sentinel item-child port for integration-final

Current checkout: `HyArpgPlugin` now registers the factory, both native block observers, `GearNativeItems.bindRecipientEffects(summonSystem::sentinelEffects)` and `summonSystem.worldUnload(worldId)`. The paragraphs below preserve the exact port contract used for that integration.

Use `skillExecutionSystem.sentinelChildPort(summonSystem)` as the fifth argument of `new NativeItemAffixBindings(loadouts, skillExecutionSystem, AppliedReceipt::acceptedDamage, AppliedReceipt::procCoefficient, sentinelChildPort)`. The factory returns `ItemSkillTriggerRuntime.Port`; it queues exact bound-item children for a later Sentinel world tick. Construct it once after `configureSummons`. Then call `summonSystem.configureSentinelItemBindings(bindings)` and register `summonSystem.sentinelBlockObserver()` after native `DamageStamina`. The summon tick drains children only for an ACTIVE durable lease, and end/removal/transfer cleanup discards pending children. Register `NativeItemAffixBindings` with the same application observer and player block hooks described in `itemskills2-result.md`. The Sentinel block observer passes a typed `ItemSkillTriggerRuntime.Block` to `bindings.sentinelBlock(block, now)` only after native post-stamina `Damage.BLOCKED` admission.

The port is deliberately distinct from `skills::enqueueItemChild`, which drains on `PlayerRef` ticks. The new Sentinel executor uses the native NPC actor and its exact lease; it does not construct a fake player.

The NPC Fire/Frost projectile child uses `RpgProjectileService`, `ProjectileModule`, `DamageCalculationService`, and `HytaleDamageAdapter` on native impact with `TRIGGERED`, `canProc=false`, zero crit chance and no leech. After actual HP loss, Fire Bolt Burn uses the existing `PeriodicStatusRuntime` and `GearStatusBindings.sharedPeriodicPort` on the NPC tick; Frost Bolt Chill uses `StatusService` and native projection. `configureSummons` installs the end/world cleanup callback for those source-owned packages. The rank-one Minor Heal uses `SupportMagnitude.healing` and the native Health writer, followed by `HytaleSupportSystem.healingResolved`; it consumes no NPC Mana. Keep the actual block observer in the registry even though a Sentinel with no native successful block cannot produce WA-147.

Source recipient adapter: `summonSystem.sentinelEffects(store, actor)` returns the exact one-item lease snapshot only while the actor UUID/world, registry lease, native Health and durable binding all agree. Use this in native status target and recipient lookups (WA-079/080/081, hostile displacement WA-082, critical excess WA-084, healing received WA-111). Keep an empty result for ordinary NPCs, inactive leases, owner swaps and dead actors. The Sentinel direct attack now calls `NativeGearAttackAcceptance.commit(..., SENTINEL_SINGLE_ROOT_PROC_COEFFICIENT, true, lease.token()+"/attack/"+attack)` for every affix-envelope root before channel submission, including item-trigger-only and status-only sources; the constant is an authored single-target root coefficient of 1. The hit retains a frozen NPC origin for Gather conditions.

The existing `RemoveWorldEvent` callback now calls `summonSystem.worldUnload(worldId)` alongside `itemAffixes.worldUnload(worldId)`. The summon method clears queued NPC children, source-owned periodic packages and bounded Sentinel Aura recipient projections even when native entity removal callbacks are skipped.

The plugin registers `summonSystem.sentinelBlockCostObserver()` in the native damage registry before `summonSystem.sentinelBlockObserver()`. It orders itself before `DamageStamina` and uses an actual `Damage.BLOCKED` plus native `DamageDataComponent.currentWielding.staminaCost` witness, then reuses `NativeAffixBlockCostSystem.apply` with `summonSystem.sentinelEffects(store, victim)`. An NPC without native block capability never receives an invented block.

`configureSummons` now injects the real `SkillExecutionService` into `HytaleSummonSystem`. `configureSentinelItemAuras` passes it to `NativeSentinelItemAuras`; fixed rank-one D08 contexts now come from `SkillExecutionService.boundItemAura` with exact bound item, neutral NPC chassis attributes and zero NPC Mana cost. The existing four-argument `NativeSentinelItemAuras` construction in `HyArpgPlugin` remains valid.

`HyArpgPlugin` binds `GearNativeItems.bindRecipientEffects(summonSystem::sentinelEffects)`. `GearNativeItems.recipientEffects` keeps player equipment for player targets and uses the live Sentinel lease only for native recipients. `GearStatusBindings`, `HytaleAreaStatuses`, `AreaNpcControlSystem`, `NativeAffixHostileDisplacement`, `HytaleDamageAdapter` and `HytaleSupportSystem` now read that selector for WA-079/080/081/082/084/111. `AreaStatusProjectionSystem` remains player-only movement. The earlier local WA-084 branch in `HytaleSummonSystem.DamageGuard` was removed so the shared critical owner applies its reduction once.
