# R153 reference fallback cards by category

Forty PNG contact sheets and `index.json` cover all 590 catalog entries. The
category rigs/crops are unchanged from R152; the grayscale-only native material
rule now preserves fixed colored trim. These are representative-color fallbacks,
not screenshots of dynamic private delivery or the NPC's complete appearance.

See the [color comparison](../R153_COLOR_COMPARISON/README.md) for actual Purple /
Green material reconstruction, and the [implementation report](../R153_APPEARANCE_LIVE_COLOR_CARDS.md)
for the private on-demand pipeline and connected-validation gate.

Files are named `CATEGORY-01.png`, `CATEGORY-02.png`, etc. All card/hash/rig coverage
is checked by `tools/test_appearance_category_rigs.py`.
