# R152 category contact sheets

All 590 reference cards, grouped by category across 40 sheets. Each card is shown at its baked 184×298 resolution (the unchanged UI displays 92×149). Labels are outside the card viewport. `index.json` records every sheet SHA-256 and its exact cosmetic keys. Skin Features has no entries in the pinned catalog.

These are **representative baked colors**, not the active NPC draft color. Compare framing/landmarks within a category, not clothing color against the live preview. R152 does not alter appearance authority or UI layout.

Overtop was reviewed across all six sheets against the supplied native MyAvatar torso screenshot: no neutral head/face, fixed neckline/waist/leg landmarks, and garment-focused composition. Other category rigs were visually reviewed using their grouped sheets. Large hair/hat tips and long garment extremities can be clipped by the fixed crop; they never trigger per-item zoom. The live preview remains available for the complete selected appearance.
